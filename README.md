# # 🎓 Student Management System

A simple and efficient system to manage student records, including adding, updating, and viewing student details. This project is built to demonstrate core programming concepts and data handling.

---

## 🚀 Features  

- ➕ Add new student records  
- ✏️ Update student information  
- ❌ Delete student data  
- 📋 View all students  
- 🔍 Search student by ID or name  
- 💾 Data handling and storage  

---

## 🛠️ Tech Stack  

- 💻 C / C++  
- 🧠 Data Structures  
- ⚙️ CLI (Command Line Interface)  

---

## 📁 Project Structure  

```
Student-Management-System/
│
├── main.cpp
├── student.cpp
├── student.h
└── data/
```

---

## ▶️ How to Run  

1. Clone the repository  
```bash
git clone https://github.com/beingkunth-source/Student-Management-System-.git
```

2. Navigate to the folder  
```bash
cd Student-Management-System-
```

3. Compile the code  
```bash
g++ main.cpp -o sms
```

4. Run the program  
```bash
./sms
```
